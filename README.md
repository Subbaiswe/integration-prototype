# Integration Prototype

This repository contains a working prototype of an open-source integration platform using NiFi, Pulsar, Camel, Airflow, and other components deployed on Azure AKS.
The goal is to understand, document, and deploy each component step-by-step while learning GitHub, Azure, and Kubernetes fundamentals.

## Get Started

1. Clone the repository  
   git clone <your-repo-url>

2. Navigate into the directory  
   cd integration-prototype

3. Follow the instructions in the infra/ and apps/ folders to deploy each component.
